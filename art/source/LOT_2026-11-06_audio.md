## En attendant : sons de remplacement synthétisés

Pour que le jeu, les tests et le mixage soient prêts, chaque identifiant du plan a un son de remplacement synthétisé
localement (`tools/audio/synth_placeholders.py` : partiels sinusoïdaux, bruit à graine, réverbération circulaire pour
des boucles sans couture ; aucun échantillon, aucune source extérieure). Ils passent par la même chaîne
(`tools/audio/process_audio.py` : boucle, sonie EBU R128, mono pour les effets, Ogg Vorbis) et sont listés avec
`"origin": "placeholder"` dans `art/source/audio/processed.json`. Total : 46 fichiers, 2,4 Mo.

Reprise une fois le solde rechargé (ordre conseillé : la cloche, puis les boucles musicales) :

```bash
python3 tools/fal/audio.py run bell music_title   # une ligne « en cours » par appel, refus au-delà de 5,00
python3 tools/fal/audio.py run --all              # le reste du plan
python3 tools/audio/process_audio.py              # remplace chaque son de remplacement par la sortie fal
```

Le poids prévu avec les sorties fal (8 boucles de ~95 s en Vorbis q2 stéréo, ≈ 0,9 Mo chacune) dépasse la cible de
8 Mo : passer alors les boucles à `QUALITY['music'] = 0` (≈ 64 kb/s) ou les couper à 60 s dans `make_loop`.
